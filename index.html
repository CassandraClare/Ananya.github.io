CURRENT RESEARCH PROJECT

PG-Mem: persistent memory for language models

EXPERIMENTS IN PROGRESS

Exploring a content-addressed graph memory mechanism around a Gated DeltaNet backbone. The current experiment compares baseline PG-Mem against an updated read/write policy rather than assuming the changes help.

Candidate-only readsGather graph neighbours only for the fine-stage candidate set instead of every memory node.
Update-aware writesRepeated key/value matches can become no-ops, while changed values update an existing memory identity.
Stateful real textCarry memory across contiguous WikiText-2 windows instead of resetting every step.
MQARregression guard
Redundancywrite/update tracking
Efficiencytok/s + GPU memory

Results are intentionally not shown here yet. The experiment notebook does not claim an improvement until the baseline/final runs establish it.
